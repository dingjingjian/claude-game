# 🚂 铁路大亨 - 火车挂机游戏

横板2D火车挂机游戏，火车自动行驶，到站获取金币，解锁更多车厢！

## 🎮 游戏玩法

- 火车自动行驶，到站获取金币
- 金币可以购买车厢或升级车头
- 不同车厢有不同收益：
  - 🚃 **货车厢** - 运货赚金币（5金/秒）
  - 🚃 **客车厢** - 载人赚金币（8金/秒）
  - 🍽️ **餐车** - 客运收益+20%
  - ⛽ **油罐车** - 货运收益+15%

## ⚙️ 核心机制

### 维护费系统
- 每秒扣除维护费，等于车头等级（Lv.1=1金/秒，Lv.25=25金/秒）
- 每次升级车头，维护费 +1
- 策略核心：不能无脑升速，需要在速度和车厢之间找平衡

### 收益公式
- **被动收入** = (货运×5×油罐加成 + 客运×8×餐车加成) − 维护费
- **到站收入** = 货运到站×油罐加成 + 客运到站×餐车加成
- **离线收益** = 车厢收入 × 50%（离线不扣维护费）

### 破产系统
- 余额 < 0 时触发破产，游戏结束并重置
- 防止玩家陷入无收入的死局

### 车厢价格
- 购买时价格 ×1.5 递增
- 脱钩时价格 ÷1.5 回退（不会越买越贵）
- 脱钩退还当前价格的 33%
- 最多 5 节车厢

### 车头升级
- 每次升级速度 +10 km/h，最高 300 km/h
- 升级价格 ×2 递增
- 速度越高维护费越高，需同步增加车厢

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动游戏
npm start
```

游戏将在 http://localhost:8080 打开

```
claude-game/

```

## 🎯 游戏特性

- ✅ 火车自动行驶 + 视差滚动背景
- ✅ 多种车站类型（货运站、客运站、综合站）
- ✅ 车厢购买/脱钩系统（价格对称回退）
- ✅ 车头升级系统（速度+维护费联动）
- ✅ 维护费系统（随车头等级线性增长，策略性升速）
- ✅ 破产系统（余额<0时游戏重置）
- ✅ 离线收益（50%效率，不扣维护费）
- ✅ 自动存档（LocalStorage，30秒间隔）
- ✅ 装卸货等待（到站后5秒装卸时间）
- ✅ 程序化生成占位图（后续替换为写实美术）
