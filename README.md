# 🚂 中国铁路 - 火车挂机游戏

横板2D火车挂机游戏，火车自动行驶，到站获取金币，解锁更多车厢！

## 🎮 游戏玩法

- 火车自动行驶，到站装卸货获取金币
- 玩家通过右侧控制杆拖拽手动调节速度（0 ~ 车头极速）
- 金币可以购买车厢或升级车头
- 不同车厢有不同收益：
  - 🚃 **货车厢** - 运货赚金币（到站为主：120金/次，每秒6金）
  - 🚃 **客车厢** - 载人赚金币（每秒为主：10金/秒，到站10金）
  - 🍽️ **餐车** - 客运每秒收益 +40%/节（不加成到站）
  - ⛽ **油罐车** - 货运到站收益 +200%/节，自身到站收入 30金/次

## ⚙️ 核心机制

### 维护费系统
- 公式：max(3, 速度 × 0.05)，最低 3 金/秒
- 速度越快维护费越高，低速运行更省钱
- 策略核心：在速度、收益、维护费之间找平衡

### 收益公式
- **每秒收入** = 货运×6 + 客运×10×(1+餐车×0.4) − 维护费
- **到站收入**：
  - 货运站：货运×120×(1+油罐×2) + 油罐×30×(1+油罐×2)
  - 客运站：客运×10
  - 综合站：货运×100×(1+油罐×2) + 油罐×30×(1+油罐×2) + 客运×8
- **装卸时间** = 5秒（到站后自动减速→停车→装卸→恢复，期间锁定玩家操作）
- **离线收益** = 车厢每秒收入 × 50%（离线不扣维护费，离线期间里程也累计）

### 进站减速 & 信号灯系统
- 火车接近车站时自动限速，信号灯亮**黄灯**（减速预警）
- 到站停车装卸时亮**红灯**（禁止通行）
- 出站离开发车时亮**绿灯**（允许通行），3秒后信号灯熄灭
- 信号灯采用真实铁路信号机外观（红/黄/绿三色灯位 + 月白引导灯）

### 车站生成
- **按距离生成**，基准距离 1.5 公里，随机范围 1.05 ~ 1.95 公里
- 停车时不会生成新车站
- 综合站始终随机出现
- 货运站仅在有货车/油罐车时出现
- 客运站仅在有客车/餐车时出现
- 每种车站有多张随机图片（freight×4, passenger×5, mixed×1）
- 配置文件 `assets/station/stations.json`，可独立调整每张图片的缩放和偏移

### 破产系统
- 余额 < 0 时触发破产，弹出结算画面（显示到站次数、总收入）
- 防止玩家陷入无收入的死局

### 车厢系统
- 购买时价格 ×2 递增（向上取整到整齐数字）
- 脱钩时价格 ÷2 回退
- 脱钩不返还金币
- 车厢上限随车头等级解锁：
  - Lv.1~4:   最多 2 节
  - Lv.5~9:   最多 3 节
  - Lv.10~14: 最多 4 节
  - Lv.15+:   最多 5 节

### 车头升级 & 皮肤系统
- 每次升级速度 +10 km/h，最高 300 km/h
- 升级价格 ×1.5 递增（向上取整到整齐数字，升满约 2.5-3 小时）
- 升级后玩家可手动将控制杆推到更高速度
- 皮肤根据等级自动切换：
  - Lv.1-5:   蒸汽机车
  - Lv.6-10:  内燃机车
  - Lv.11-15: 电力机车
  - Lv.16-20: 和谐型电力
  - Lv.21+:   复兴号动车组
- 蒸汽机车有蒸汽粒子特效（烟囱 + 气缸双发射源），内燃及以上无蒸汽

### 速度控制
- 右侧纵向控制杆，拖拽调节目标速度（0 ~ 车头极速）
- 手柄颜色渐变：绿（低速）→ 黄（中速）→ 红（高速）
- 加速度 50 km/h/s，减速度 100 km/h/s（刹车比起步快）
- 进站时自动减速并锁定玩家操作，装卸完毕后恢复

### 蒸汽系统
- 烟囱蒸汽：速度越快飘移越密集，sigmoid 曲线控制频率
- 气缸蒸汽：停车时仍持续冒出（模拟气缸排气）
- Tween 驱动粒子，兼容性好，无需 WebGL 粒子系统

### 运行里程
- 实时累计行驶距离（公里），>1000km 时显示 k 为单位
- 离线期间也按最后速度计算里程

### 设置面板
- 左下角齿轮按钮打开设置弹窗
- 语言切换（中/English）
- 音效开关（🔊/🔇）
- 游戏重置（二次确认）
- 打开设置时自动暂停游戏，关闭后自动恢复

### 语言系统
- 支持中文 / English 切换
- 设置面板内切换，实时刷新所有文本
- 语言偏好存入 LocalStorage

### 音效系统
- 8 个音效 + BGM：
  - `click` — UI 按钮点击
  - `buy` — 升级车头
  - `buy-carriage` — 购买车厢
  - `gold` — 到站金币
  - `uncouple` — 解挂车厢
  - `signal` — 信号灯亮起
  - `whistle` — 到站/出发汽笛
  - `train-run` — 行驶循环音（loop，随速度变调）
  - `bgm` — 背景音乐
- 浏览器自动播放限制通过"点击开始游戏"启动画面解决

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器（无缓存）
npm run dev

# 启动生产服务器
npm start
```

游戏将在 http://localhost:8080 打开

## 🎯 游戏特性

- ✅ 火车自动行驶 + 7层视差滚动背景（天空PNG、远山PNG、远云/近云PNG、中景草地、近景树木PNG、地面PNG、铁轨PNG）
- ✅ 火车头皮肤系统（5 种车头，等级提升自动切换，蒸汽仅蒸汽机车有）
- ✅ 蒸汽粒子系统（烟囱 + 气缸双发射源，Tween 驱动，sigmoid 速度曲线）
- ✅ 铁路信号灯系统（黄/红/绿三色灯位，真实信号机外观，进站/停车/出站三态切换）
- ✅ 三种车站类型，多张随机图片，按距离随机生成，配置文件可调
- ✅ 车厢购买/脱钩系统（价格对称回退，脱钩不返金币，车厢上限随等级解锁）
- ✅ 车头升级系统（速度 +10km/h/次，上限 300km/h，价格 ×1.5）
- ✅ 速度控制杆（拖拽交互，绿→黄→红渐变手柄，三态同步）
- ✅ 维护费系统（仅与速度挂钩，最低 3 金/秒）
- ✅ 经济系统（客运稳定流 vs 货运爆发流，油罐车/餐车有存在感）
- ✅ 破产系统（余额 <0 时弹出结算画面并重置）
- ✅ 离线收益（50% 效率，不扣维护费，离线里程也累计）
- ✅ 运行里程统计（实时 + 离线累计，自适应单位显示）
- ✅ 音效系统（8 个音效 + BGM，行驶音随速度变调）
- ✅ 设置面板（语言切换、音效开关、游戏重置，自动暂停/恢复）
- ✅ 中英文切换（LocalStorage 记忆语言偏好）
- ✅ 自动存档（LocalStorage，30 秒间隔，页面关闭/隐藏时也保存）
- ✅ 移动端适配（横屏检测提示、触摸事件防滚动、FIT 自适应缩放）
