# 🚂 中国铁路 - 火车挂机游戏

横板2D火车挂机游戏，火车自动行驶，到站获取金币，解锁更多车厢！

## 🎮 游戏玩法

- 火车自动行驶，到站装卸货获取金币
- 玩家通过控制杆手动调节速度（0 ~ 极速）
- 金币可以购买车厢或升级车头
- 不同车厢有不同收益：
  - 🚃 **货车厢** - 运货赚金币（到站为主：25金/次，每秒2金）
  - 🚃 **客车厢** - 载人赚金币（每秒为主：10金/秒，到站10金）
  - 🍽️ **餐车** - 客运每秒收益 +20%/节（不加成到站）
  - ⛽ **油罐车** - 货运到站收益 +20%/节（不加成每秒）

## ⚙️ 核心机制

### 维护费系统
- 公式：(车头等级+1) × (1 + 当前速度/100)，最低 2 金/秒
- 速度越快维护费越高，低速运行更省钱
- 策略核心：在速度、收益、维护费之间找平衡

### 收益公式
- **每秒收入** = 货运×2 + 客运×10×(1+餐车×0.2) − 维护费
- **到站收入** = 货运站: 货运×25×(1+油罐×0.2) / 客运站: 客运×10 / 综合站: 两者叠加
- **装卸时间** = 5秒（到站后自动装卸，期间不可操作速度）
- **离线收益** = 车厢每秒收入 × 50%（离线不扣维护费）

### 破产系统
- 余额 < 0 时触发破产，游戏结束并重置
- 防止玩家陷入无收入的死局

### 车厢系统
- 购买时价格 ×1.5 递增（向上取整到10的倍数）
- 脱钩时价格 ÷1.5 回退（向下取整到10的倍数，不会越买越贵）
- 脱钩不返还金币
- 最多 5 节车厢

### 车头升级
- 每次升级速度 +10 km/h，最高 300 km/h
- 升级价格 ×2 递增
- 升级后玩家可手动将控制杆推到更高速度

### 速度控制
- 右侧纵向控制杆，拖拽调节目标速度（0 ~ 车头极速）
- 加速度 200 km/h/s，减速度 40 km/h/s（减速更灵敏）
- 进站时自动减速并锁定玩家操作，装卸完毕后恢复

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器（无缓存）
npm run dev

# 启动生产服务器
npm start
```

游戏将在 http://localhost:8080 打开

## 🎯 游戏特性

- ✅ 火车自动行驶 + 视差滚动背景（天空、远山、近山、地面）
- ✅ 蒸汽系统（烟囱+气缸双发射源，速度越快飘移越密集）
- ✅ 多种车站类型（货运站、客运站、综合站），到站自动装卸
- ✅ 车厢购买/脱钩系统（价格对称回退，脱钩不返金币）
- ✅ 车头升级系统（速度+10km/h/次，上限300km/h）
- ✅ 玩家手动速度控制杆（拖拽/自动操作/进站锁定三态同步）
- ✅ 维护费系统（随等级和速度联动，低速省钱）
- ✅ 破产系统（余额<0时游戏重置）
- ✅ 离线收益（50%效率，不扣维护费）
- ✅ 自动存档（LocalStorage，30秒间隔）
- ✅ 程序化生成占位图 + 真实素材混合
