# 🚂 铁路大亨 - 火车挂机游戏

横板2D火车挂机游戏，火车自动行驶，到站获取金币，解锁更多车厢！

## 🎮 游戏玩法

- 火车自动行驶，到站获取金币
- 金币可以解锁更多车厢或升级车头
- 不同车厢有不同收益：
  - 🚃 **货车厢** - 运货赚金币
  - 🚃 **客车厢** - 载人赚金币
  - 🍽️ **餐车** - 提升收益20%
  - ⛽ **油罐车** - 降低油耗15%

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动游戏
npm start
```

游戏将在 http://localhost:8080 打开

## 🎯 游戏特性

- ✅ 火车自动行驶
- ✅ 多种车站类型（货运站、客运站、综合站）
- ✅ 车厢升级系统
- ✅ 车头升级系统
- ✅ 离线收益（50%效率）
- ✅ 自动存档（LocalStorage）
- ✅ 占位图美术（后续替换为写实风格）
